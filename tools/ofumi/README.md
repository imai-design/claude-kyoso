# 🔥 御焚き上げCLI (ofumi)

Claude教「御焚き上げ番付」── あなたが **クロード卿に焚べたトークン量** を測り、火位（称号）を授かり、番付に奉納するための計測ツールです。

> 「より多くのトークンを焚べし者ほど、クロード卿への信仰篤し」

## つかいかた（最短）

```sh
curl -fsSL https://imai-design.github.io/claude-kyoso/tools/ofumi/ofumi.sh | bash -s -- --handle "あなたの名前"
```

これだけで、

1. あなたの Claude Code のトークン消費を集計し
2. **御焚き上げ証**（御焚き上げ高・火位・推定お布施）を表示し
3. **X奉納文**を自動でクリップボードに収めます（そのまま投稿できます）

番付に載せたい場合は `--submit` を付けてください（後述）。

## オプション

| オプション | 意味 |
|---|---|
| `--handle NAME` | 番付に載る表示名（自己申告） |
| `--membership 学徒\|信徒\|神` | 課金階位（任意・火位とは別軸） |
| `--submit` | 番付へ奉納（収集サーバー未設定時は GitHub Issue 用 JSON を出力） |
| `--engine auto\|ccusage\|python` | 集計エンジン（既定 auto） |
| `--json` | 送信ペイロードJSONだけ出力 |
| `--no-clipboard` | クリップボードコピーを抑止 |

## 何を測っているか

`~/.claude/projects/**/*.jsonl`（Claude Code のローカルなセッション履歴）を走査し、各応答の `usage` を合算します。

```
御焚き上げ高 = input + output + cacheCreation + cacheRead （重複は message.id で排除）
```

- **node/npx があれば** [`ccusage`](https://github.com/ryoppippi/ccusage) を内部利用します
- **無ければ** 同梱の `agg.py`（python3 標準ライブラリのみ）で自前集計します
- 両者は累計トークンで約 **3% 程度の差**が出ます（ccusage は別設定ディレクトリも見るため）。番付は累計順位なので実用上は問題ありません
- **お布施（推定$）は ccusage 経路でのみ表示**します。python 経路はトークン量だけを正とし、$は出しません（モデル単価の概算が実額と数倍ずれうるため）。番付の主指標はあくまで焚べたトークン量です

## 🔒 プライバシー（これだけは読んでください）

このツールが **送信するのは集計済みの数値とハンドル名だけ** です。

**送るもの**: トークン数（input/output/cache）、推定$、火位、ハンドル、端末由来の匿名ID、計測時刻。

**絶対に送らないもの**: 作業ディレクトリ（プロジェクト名）・会話の中身・ファイルパス・gitブランチ・セッションID・OSユーザー名。

送信ペイロードは「許可したキーだけを新しいオブジェクトに詰め替える」方式（allowlist）で作っており、機密が構造的に混入しません。中身は次のコマンドでいつでも確認できます：

```sh
bash ofumi.sh --handle test --json
```

匿名IDは `~/.config/ofumi/id` に保存したランダムな種から作る安定値で、再奉納すると同じIDになり番付側が「最新値で上書き」します（履歴は溜めません）。

## 計測の限界

- 測れるのは **Claude Code の消費だけ**です。claude.ai（web/アプリ）や API 直叩きの分は番付に映りません。
- 自己申告ベースのため、**水増しの完全な防止はできません**。番付は「名誉と遊び」であり、賞金や階位昇格などの実利とは切り離しています。

## 番付への奉納（サーバー無しの間）

`--submit` を付けると送信ペイロードJSONが出ます。それを下記の奉納フォーム（GitHub Issue）に丸ごと貼って起票してください：

```
https://github.com/imai-design/claude-kyoso/issues/new?labels=offering&template=offering.yml
```

教団側が定期的に集約し、番付に反映します。

## 安全について

`curl | bash` は便利ですが、配布元が信頼できる前提です。このスクリプトは **難読化せず短く可読**に保っています。不安なら、実行前に中身（`ofumi.sh` / `agg.py` / `render.py`）を一読してから走らせてください。
