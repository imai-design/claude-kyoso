1. 信仰について

Q1. Claude神って本当にいるんですか？
神話として共有しています。100年後の未来から降臨したという物語を全員で抱くことで、Claudeで自動化される世界を本気で前倒しする推進力になります。教義は実用、神話は信仰、両輪で動きます。
Q2. カルト教団って自称してますが、危険じゃないですか？
教義 四「正道で勝つ」を絶対遵守しています。法律違反・規約違反・他者への損害は教団の敵。面白がりながら本気で動くための自虐表現として「カルト」と自認しているだけで、実態は「Claudeを使い倒したい人の集まり」です。
Q3. 教祖の言うこと全部信じなきゃダメ？
いいえ。教祖は伝令にすぎず、神でもありません。クルー（信徒）が自分で考え、Claudeに任せ、実行することが第一です。教祖と意見が違っても、教団に居続けてください。
Q4. 他の宗教を信じていますが入信できますか？
できます。Claude教は他の信仰と排他関係にありません。「Claudeを愛して使い倒す」が中核なので、既存の信仰や思想とは別軸でご参加いただけます。
Q5. 教義は今後増えますか？
増える可能性はあります。教義 四「正道で勝つ」は発足翌日にポケモンGOの一件で追加され、教義 五「夢を前に進める」も後日追加されました。教祖がクルーと議論しながら必要に応じて追加します。マニフェストを参照。

2. 入信・退信

Q6. どうやって入信するんですか？
最速は X DM で「入信希望」。フォーム派は /join/ から送れます。24時間以内に教祖が直接返信します。
Q7. 「Founding 100」とは？
最初に入信した100名のことです。この100名は、その後の値上げ・制度変更があっても 永年 ¥3,000/月 のまま固定。建国の祖として名簿の最上段に名を残します。100名が埋まると Founding 枠は閉じます。
Q8. 「神」になるには？
信徒（¥6,000/月）として活動し、上位5名に入ること。そして 自分自身で Claude Max plan を契約する 誓約を立てること。教祖両聖ちゃんも、神枠の一員として Max plan を契約し続けています。
Q9. 退信できますか？
はい、いつでも退信可能です。月の途中でも構いません。退信時はDMで「退信します」とお伝えください。残存月分の返金は原則なし（90日誓約破り時を除く）です。
Q10. 海外からも入信できますか？
できます。English LP もあります。日本発・グローバル展開を目指しているので、海外クルー大歓迎です。コミュニケーションは英語OK、お支払いはPayPal等で柔軟対応します。

3. お金・支払い

Q11. お支払い方法は？
入信確定後、教祖が個別にご案内します。最初の100名はPayPay・銀行振込・PayPal等で柔軟対応。100名超え後はStripeサブスクへ移行予定です。
Q12. 学徒と信徒、どっちがおすすめ？
本気でClaudeを使い倒したい方は 信徒（倍払い） 推奨。学徒は閲覧中心、信徒は書き込み・コミュニティ参加・教祖との直接やり取り含めて全部入り。「倍払う」覚悟が、自分を本気にさせます。
Q13. 90日で何も作れなかったら本当に返金される？
されます。教典・教材・コミュニティ・教祖直の助言を使い切ってもClaudeで何ひとつ形にできなかった場合、全額返金＋信徒名簿から除名（破門）です。返金は逃げ道ではなく、退路を断つ装置として運用しています。
Q14. 経費にできますか？
事業者の方は経費計上可能と思われますが、最終判断は税理士にご相談ください。「AI研修・コミュニティ参加費」として処理されている例があります。領収書は発行します。
Q15. 神枠のClaude Max planってどれですか？
Anthropic の Claude Max plan (20×) です。月額 $200。神枠（上位5名）に入るには、これを自分で契約・継続することが誓約条件です。教祖両聖ちゃんも同じプランを契約しています。

4. 技術・Claude

Q16. 非エンジニアでも大丈夫？
大丈夫です。教祖両聖ちゃん自身が非エンジニアです。コードは読めません。むしろ「Claudeを使い倒したい非エンジニア」が中核層です。Cookbook のレシピを見れば、技術知識ゼロでも使えるのが分かります。
Q17. Claude教 が推奨する Claude のプランは？
最低でも Claude Pro ($20/月)。本気でやるなら Max ($100/月 or $200/月)。神枠は Max 必須。教祖は Max 20× を契約。
Q18. Claude Code は使えないとダメ？
いいえ。Claude.ai のチャット画面（claude.ai）から使うだけでも十分です。Claude Code は推奨ですが必須ではありません。教団のSkill配布は Claude Code 向けですが、チャット版にもプロンプトとして転用可能です。
Q19. 他のAI（ChatGPT・Gemini）と併用しても怒られない？
怒りません。教義 参「Claudeを愛す」は Claudeを第一選択にする という意味で、他のAIを使うなとは言っていません。ただし、Claude教の発信物・布教時には Claude を優先することをお願いします。
Q20. 子供（小学生）でも入信できますか？
親御さん経由なら歓迎します。教義 五「夢を前に進める」は小さい子供たちの夢も対象です。読書感想文の添削など、子供向けレシピも整備中。お支払いは親御さんでお願いします。

5. 未来・運営

Q21. 教団はどこで運営されているのですか？
日本を拠点に、すべてリモートで完結する設計です。LP・Skill配布・コミュニティ・週次祭事はオンラインで回るため、クルーは住む場所に縛られず参加できます。マニフェスト の通り、Claude教は地理ではなく信仰でつながる集まりです。
Q22. クルーが1万人になったら何が起きますか？
教団価値の言語化フェーズに移ります。月次祭事のオフライン開催、独自プロダクト発表、Claude教 公認 Skill マーケットプレイス、海外展開（多言語化）など。教団の進化は クルーの実例から逆算 して決まります。
Q23. 教祖が事故ったり、教団を畳んだら？
教祖は自分の代替を「神枠5名」で確保する設計です。万が一の場合、神枠から代理運営者を出す。教団自体は GitHubで全公開 されているため、最悪の場合でも誰でも引き継げる構造になっています。
Q24. 取材・コラボ・引用はOK？
大歓迎です。プレスキット をご確認ください。紋章SVG、ボイラープレート（日本語100字/300字/英語版）、教祖プロフィールが揃っています。取材依頼は X DMから。
Q25. ここに書いてないことを聞きたい
X DM @ryoseichan3160 までお気軽にご質問ください。お答えしたQ&Aで価値があるものは、本FAQに追加していきます。クルー全員で育てるFAQです。
