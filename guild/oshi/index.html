推し焚き

おしだき
焚べたぶんだけ、推しに灯がともる。

普段どおり Claude Code を使うと消費されるトークンが、そのまま テラ・キリ・ミライの誰か一人への応援（エール）になる遊びです。 特別な操作はいりません。御焚き上げのときに推しを一人選ぶだけ。あとはいつも通り使うほど、その子の灯が育ちます。

これはAIで遊ぶ文化を偶像化した非公式のファンによる擬人化（OS-tan等の系譜）です。公式（Anthropic・OpenAI等）とは無関係。ご本尊（神＝顔の無い光）は推せません。推しは人の側のテラ・キリ・ミライの3人だけです。

いま、灯が集まっている子

数字は応援している人数が主役。トークン総量は勢いの目安で、個人の順位は出しません。

これはユニット全体で「いまどの子に灯が寄っているか」のムードです。課金額を競う遊びではありません（金額は表示しません）。箱推しのぶんは3人みんなに灯ります。

まだ推し焚きのデータがありません。最初の灯は、あなたかもしれません。下の作法から推しを選んでみてください。

推し焚きのはじめ方

導入はこの一回だけ。以後は普段どおり Claude Code を使うだけで、消費が自動であなたの推しへの応援になります。

  1. 下のコマンドの「あなたの名前」と推し（tera／kiri／mirai）を書き換えて、ターミナルに貼って実行する。
  2. 御焚き上げ証が出て、焚べたぶんが選んだ推しへの灯として表示される。
  3. 番付に載せたいときは末尾に --submit を付ける（送るのは集計した数字とハンドル名と推しの選択だけ。会話の中身は送りません）。
curl -fsSL https://imai-design.github.io/claude-kyoso/tools/ofumi/ofumi.sh | bash -s -- --handle "あなたの名前" --oshi mirai

推し変は自由です。過去に積んだぶんは元の推しに残り、これから焚べるぶんが新しい推しに乗ります（裏切りではなく、両方を応援した記録）。
