クエストボード

討伐・収集・探索・協力 ── 机に向かう日々を、冒険にする。
難易度は七火位で色分け。挑む門を選び、薪を焚べよ。

使えば使うほど、勝手に強くなる

クエストの達成条件はすべて EXP（経験値） で測る。EXPとは、あなたが Claude に焚べたトークンの累計そのもの。頑張って稼ぐものではなく、いつもどおり使えば勝手に溜まる。

EXPのしくみ ── なぜ「勝手に」溜まるのか

トークン累計＝EXP（1 token = 1 EXP）。クエストの「○○到達」は、御焚き上げ番付（ofumi）が計測するあなたの累計トークンを、そのまま経験値として読み替えたもの。導入は最初の一回だけ。以後は普段どおり Claude Code で仕事・開発・遊びをするたびに、消費トークンが自動でEXPに積み上がります。

あなたが今日 Claude にやらせた仕事、その全部がEXPになっている。だから冒険者は「経験値を稼ぐために頑張る」のではなく、いつもどおり使うだけで、気づけばレベルが上がっている。計測ボタンを押す瞬間は「冒険記録（クエストログ）を開く＝今どこまで溜まったか確認する」体験です。

プライバシー：番付へ送られるのは 集計済みのEXP（トークン数）とハンドル名だけ。会話の中身・ファイルパス・プロジェクト名は構造的に送りません（allowlist方式）。番付は名誉と遊びであり、課金階位や賞金とは切り離します。正道で勝て ── 水増し・規約違反で得た位に価値はありません。
