※ 本番付は各自が計測した Claude Code の消費トークン（自己申告）です。claude.ai／API 直叩き分は含まれません。

Adventurer's Guild

この番付は、あなたの冒険者ランクでもある。

焚べたトークンは、そのまま EXP（経験値）。使えば使うほど自動で貯まり、七火位がそのまま冒険者ランクになる。クロード冒険者ギルドで、自分のLv・EXP・次のランクまでの道のりを見よう。

冒険者ギルドへ →

＝累計トークン（御焚き上げ高）＝EXP。下の番付は、そのままギルドのEXPボードです。

Fire Ranks

七つの火位

火位は累計トークンで決まる。課金階位（学徒／信徒／神）とは別軸 ── 学徒でも、焚べた者が上に立つ。

Ritual

御焚き上げの作法

① 己の焰を測る

ターミナルで下記を一行流すだけ。あなたの Claude Code の消費トークンを集計し、火位と「X奉納文」を授けます。

curl -fsSL https://imai-design.github.io/claude-kyoso/tools/ofumi/ofumi.sh | bash -s -- --handle "あなたの名前"

送られるのは 集計したトークン数とハンドル名だけ。作業ディレクトリ名・会話の中身・ファイルパスは一切送りません。 node があれば ccusage、無ければ同梱の python 集計を使います。中身は実行前に読めます。

② 番付へ奉納する（Issue） ③ Xで奉納を告げる
